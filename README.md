# Mipega.cl – web

Calculadoras laborales de Chile (finiquito, horas extras, licencias, renuncia y más).
Este repositorio contiene solo los archivos compilados (sitio estático) de la web de Mipega.cl.

- Contacto: mipega.app@gmail.com
- Mipega es una app independiente y no representa al Gobierno de Chile. Los cálculos son referenciales.
- Publicación: Render (Static Site), `publishPath: ./`, con rewrite `/*` → `/index.html`.
